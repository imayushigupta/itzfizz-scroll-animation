# ITZFIZZ Scroll Animation

A scroll-driven hero section built with React, Vite, GSAP, and Tailwind CSS.

## Features

* Scroll-based animation
* Interactive hero section
* GSAP animation effects
* Responsive design

## Tech Stack

* React
* Vite
* GSAP
* Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the project.
